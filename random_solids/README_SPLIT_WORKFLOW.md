# Solid Generation and Reconstruction - Split Workflow

This directory contains a split workflow for solid generation and reverse engineering:

## Files

1. **V6_current.py** - Original combined workflow (unchanged)
2. **Build_Solid.py** - Part 1: Solid generation and engineering drawings
3. **Reconstruct_Solid.py** - Part 2: Reverse engineering and reconstruction

## Workflow

### Part 1: Build Solid and Create Engineering Drawings

```bash
python Build_Solid.py --seed 55
```

**What it does:**
- Builds a random 3D solid using the specified seed
- Extracts face polygons from the solid
- Creates 4 engineering views (Top, Front, Side, Isometric)
- Generates connectivity matrices for each view
- Saves data to files:
  - `Output/solid_faces_seed_55.npy` - Face polygon vertices
  - `Output/connectivity_matrices_seed_55.npz` - View matrices
- **Shows:** Four-view engineering drawing plot

**Options:**
```bash
--seed 55               # Random seed for solid generation
--normal 1,1,1          # Projection normal for isometric view
--rotate 0,0,0          # Rotation angles (degrees) for X,Y,Z axes
--config-file path.yml  # Load configuration from file
--save-config           # Save configuration to file
--output-dir Output     # Directory for output files
--quiet                 # Suppress verbose output
```

### Part 2: Reconstruct Solid from Views

```bash
python Reconstruct_Solid.py --seed 55
```

**What it does:**
- Loads connectivity matrices from saved files
- Filters candidate vertices using orthogonal projections
- Builds merged connectivity matrix (sum of 3 views)
- Extracts polygon faces from connectivity
- **Shows:** 
  - 3D solid with reconstructed edges
  - Extracted polygon faces (interactive 3D plot)

**Options:**
```bash
--seed 55               # Must match the Build_Solid.py seed
--input-dir Output      # Directory containing saved matrices
--tolerance 1e-6        # Tolerance for face coplanarity
```

## Example Usage

```bash
# Step 1: Build solid and create views
python Build_Solid.py --seed 55 --normal 1,1,1

# Step 2: Reconstruct from views
python Reconstruct_Solid.py --seed 55

# Try different seeds
python Build_Solid.py --seed 12345
python Reconstruct_Solid.py --seed 12345

# With rotation
python Build_Solid.py --seed 55 --rotate 15,30,0
python Reconstruct_Solid.py --seed 55
```

## Output Files

### Generated by Build_Solid.py:
- `Output/solid_faces_seed_XXXXX.npy` - Face polygons with outer boundaries and holes
- `Output/connectivity_matrices_seed_XXXXX.npz` - Compressed file containing:
  - `all_vertices` - Original 3D vertices from solid
  - `top_view_matrix` - Top view connectivity (N×(3+N))
  - `front_view_matrix` - Front view connectivity (N×(3+N))
  - `side_view_matrix` - Side view connectivity (N×(3+N))
- `STEPfiles/solid_output.step` - STEP file of the solid

### Matrix Format:
Each connectivity matrix row: `[vertex_index, proj_x, proj_y, conn_0, conn_1, ..., conn_N]`
- Columns 0-2: Vertex index and 2D projection coordinates
- Columns 3+: Connectivity to other vertices (0=no edge, 1=edge exists)

## Key Differences from V6_current.py

**Build_Solid.py:**
- Focuses on solid generation and view creation
- Saves intermediate data files
- Shows only the 4-view engineering drawing

**Reconstruct_Solid.py:**
- Focuses on reverse engineering
- Loads pre-computed connectivity matrices
- Shows only reconstruction plots (edges and faces)

**V6_current.py:**
- Original file (unchanged)
- Runs entire workflow in one execution
- Shows all plots
- Used for development and testing

## Dependencies

Both scripts require:
- numpy
- matplotlib
- shapely
- pythonocc-core (OpenCASCADE)
- Custom modules: `Reconstruction.config_system`, `Reconstruction.Base_Solid`, `opencascade`

## Notes

- The seed value must match between Build_Solid.py and Reconstruct_Solid.py
- Output directory must be accessible to both scripts
- Original face polygons are loaded by Reconstruct_Solid.py for visualization comparison but are not used in the reconstruction algorithm
- The reconstruction uses only the connectivity matrices from the three orthogonal views
